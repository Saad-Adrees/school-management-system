# 🏫 School Management System

A full-stack web application built with **Laravel**, **MySQL**, and **Tailwind CSS** designed to streamline administrative workflows, student record tracking, attendance management, and academic reporting.

---

## 🚀 Features

* **Dynamic Dashboard:** Real-time metrics pulling total counts for students, teachers, and active classes directly from the database.
* **Student & Teacher Management:** Full CRUD operations for managing student enrollments and staff profiles.
* **Attendance Tracker:** Comprehensive module to log and monitor daily attendance across different classes.
* **Marks & Report Cards:** System for recording student academic performance and generating report cards.

---

## 🛠️ Tech Stack

* **Backend:** PHP 8.x, Laravel 11.x
* **Frontend:** Blade Templating, Tailwind CSS, Alpine.js / Vite
* **Database:** MySQL / phpMyAdmin
* **Version Control:** Git, GitHub
